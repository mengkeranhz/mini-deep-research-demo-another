# Source First Report

## 工作流程

1. 调用 `analyze_query`，把报告拆成“事实检索”“交叉核验”“对比分析”“结论撰写”四类任务。
2. 每个关键数据维度写入 `required_facts`，时期必须逐项枚举。
3. 优先检索官方机构、原始发布方或规范维护方；无法官方核验的数据用 `proxy` 标注。
4. 每获得一条事实立即 `record_fact`，不要等待全部检索结束。
5. 汇总前检查任务是否全部 done、事实覆盖是否无缺口。
6. `final_answer` 输出：结论、关键数据表、口径说明、限制与缺口、编号来源。

## 终检

- 每个关键数值都有 `[来源N]` 紧邻映射。
- `not_found` 和 `proxy` 均需显式说明。
- 不新增账本不支撑的确定性事实。
